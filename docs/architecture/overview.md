# SOFIA Architecture Overview

## Core Engine

The SOFIA Core exposes the module registry and configuration discovery.

## Knowledge Engine

The knowledge layer will index documentation, runbooks, incidents, scripts, GLPI, and RFC content.

## Workflow Engine

The workflow layer will coordinate event-driven automation.

## Provisioning Engine

The provisioning layer will install components using Compose and orchestrated health checks.

## Monitoring Engine

The monitoring layer will integrate with Zabbix, Grafana, and metrics backends.

## AI Engine

The AI engine will derive recommendations based on Knowledge and Workflow context.

## MCP Engine

The MCP engine will expose capabilities from registered modules as tool surfaces.

## Studio Engine

The Studio engine will support visual composition of modules, connectors, and workflows.
