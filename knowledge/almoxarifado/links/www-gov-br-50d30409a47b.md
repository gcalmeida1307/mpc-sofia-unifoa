Portal de Dados Abertos em Compras Públicas do Governo Federal
O que são dados abertos?
Dados Abertos são informações que podem ser livremente acessadas, utilizadas, reutilizadas e redistribuídas por qualquer pessoa.
Este portal disponibiliza dados do Sistema Integrado de Administração e Serviços Gerais (SIASG) e do Compras.gov.br, abrangendo todo o ciclo de contratações públicas do Governo Federal e organizando o acesso à documentação técnica e aos recursos de reuso.
Planejamento de Entregas
Acesse, explore e integre dados estruturados sobre licitações, contratos e fornecedores de toda a administração pública brasileira em um único lugar.
Painéis
Dashboards, indicadores e painéis que ajudam a interpretar o ecossistema de contratações públicas.
API de Dados Abertos
API oficial de dados abertos de compras públicas com acesso, via protocolo REST, às informações do SIASG e do Compras.gov.br.
Explorador de Dados
Navegue por módulos, entenda a estrutura da API e consulte dados públicos por endpoint.
Repositório CSV
Acesse arquivos CSV publicados com dados abertos de compras governamentais para uso analítico e operacional
Pesquisa de Preços em Dados Abertos
Consulte referências e comparações de preços praticados em materiais e serviços do ecossistema de compras públicas
Dados Abertos - CGU
Portal da CGU - contém informações das compras públicas realizadas no sistema SIASG/Compras.gov.br
Documentação e Manuais
Acesse manuais, referências técnicas e o catálogo público de módulos e endpoints da API.

Portal de Dados Abertos em Compras Públicas do Governo Federal
O que são dados abertos?
Dados Abertos são informações que podem ser livremente acessadas, utilizadas, reutilizadas e redistribuídas por qualquer pessoa.
Este portal disponibiliza dados do Sistema Integrado de Administração e Serviços Gerais (SIASG) e do Compras.gov.br, abrangendo todo o ciclo de contratações públicas do Governo Federal e organizando o acesso à documentação técnica e aos recursos de reuso.
Planejamento de Entregas
Acesse, explore e integre dados estruturados sobre licitações, contratos e fornecedores de toda a administração pública brasileira em um único lugar.
Painéis
Dashboards, indicadores e painéis que ajudam a interpretar o ecossistema de contratações públicas.
API de Dados Abertos
API oficial de dados abertos de compras públicas com acesso, via protocolo REST, às informações do SIASG e do Compras.gov.br.
Explorador de Dados
Navegue por módulos, entenda a estrutura da API e consulte dados públicos por endpoint.
Repositório CSV
Acesse arquivos CSV publicados com dados abertos de compras governamentais para uso analítico e operacional
Pesquisa de Preços em Dados Abertos
Consulte referências e comparações de preços praticados em materiais e serviços do ecossistema de compras públicas
Dados Abertos - CGU
Portal da CGU - contém informações das compras públicas realizadas no sistema SIASG/Compras.gov.br
Documentação e Manuais
Acesse manuais, referências técnicas e o catálogo público de módulos e endpoints da API.
